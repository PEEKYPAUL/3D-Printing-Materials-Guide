# Code of Conduct

## Our Standards

This is a technical reference guide for the 3D printing community. Everyone who contributes, comments, or raises issues is expected to:

- Be respectful and constructive in all interactions
- Focus feedback on content accuracy, not on individuals
- Accept that printing techniques, settings, and recommendations are often experience-dependent — disagreement should be evidenced, not dismissive
- Welcome contributors of all skill levels — beginners asking questions are as valuable as experts submitting corrections

The following will not be tolerated:

- Personal attacks, insults, or hostile language
- Dismissing contributions without explanation
- Spam, self-promotion unrelated to the guide's content, or commercial solicitation
- Sharing others' personal information without consent

## Scope

This Code of Conduct applies to all activity within this repository — issues, pull requests, discussions, and commit messages.

## Reporting

If you witness behaviour that violates this Code of Conduct, please report it by opening a private issue or contacting the repository owner directly via GitHub.

Violations will be reviewed and may result in contributions being removed or the contributor being blocked from the repository.
