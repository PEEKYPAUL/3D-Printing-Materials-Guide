# Security Policy

## Scope

This repository contains documentation and guides only — there is no software, executable code, APIs, or deployable infrastructure. As such, traditional software security vulnerabilities do not apply.

However, there are a small number of security-relevant considerations for a guide of this type:

---

## What to Report

Please report any of the following via a **private GitHub issue** or by contacting the repository owner directly:

### Dangerous or Incorrect Safety Information

If any guide contains instructions that could cause:
- **Fire risk** — incorrect temperature recommendations that could cause hotend fires, runaway thermal events, or bed surface ignition
- **Electrical hazard** — incorrect wiring, PSU, or mains wiring guidance
- **Toxic fume exposure** — missing or incorrect ventilation warnings for high-temp or specialist materials (PVDF, PEEK, PPS, etc.)
- **Mechanical injury** — unsafe tooling or machining guidance

These should be reported immediately so they can be corrected as a priority.

### Personal Information

If any committed file contains personal information that should not be public (e.g. network credentials, API tokens, personal addresses), please report it privately so it can be removed from the git history.

---

## How to Report

- **GitHub Issues** — for non-sensitive corrections, open a public issue using the Incorrect Information template
- **Private contact** — for sensitive safety concerns or personal data exposure, contact the repository owner directly via GitHub

---

## Response

Safety-critical corrections will be treated as the highest priority and addressed before any other open issues or pull requests.
